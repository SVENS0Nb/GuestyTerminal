# Sicherheitsrichtlinie

## Unterstützte Version

Sicherheitskorrekturen werden für die jeweils neueste veröffentlichte
GuestyTerminal-Version bereitgestellt. Ältere Integrations- und
Firmwareversionen sollten gemeinsam aktualisiert werden.

## Sicherheitsproblem melden

Bitte verwende bevorzugt eine private GitHub-Sicherheitsmeldung unter
<https://github.com/SVENS0Nb/GuestyTerminal/security/advisories/new>. Falls
diese Funktion nicht verfügbar ist, darf ein öffentliches Issue nur eine
neutrale Kontaktanfrage ohne technische Exploitdetails oder personenbezogene
Daten enthalten.

Niemals Guesty Client Secrets, OAuth-Tokens, Türcodes, WLAN-Passwörter,
ESPHome-API-Schlüssel, OTA-Passwörter, reale Reservierungen oder vollständige
Home-Assistant-Diagnosen öffentlich einfügen.

Eine hilfreiche Meldung nennt die betroffene GuestyTerminal-, Home-Assistant-
und ESPHome-Version, die Betriebsart des Displays und reproduzierbare Schritte
mit vollständig anonymisierten Testdaten.
